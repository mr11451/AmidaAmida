
# AmidaAmida

## 概要
AmidaAmida は C# / .NET 8 で作成されたアミダくじシミュレータです。GUI 上で軸（縦線）と横線を操作して結果を確認できます。

## 前提条件
- .NET 8 SDK
- Visual Studio 2022 以降（推奨）または dotnet CLI
- Git

## ビルドと実行
1. リポジトリをクローン:
   git clone https://github.com/mr11451/AmidaAmida.git
2. ソリューションディレクトリへ移動:
   cd AmidaAmida
3. ビルド:
   dotnet build
4. 実行:
   dotnet run --project AmidaAmida.csproj
   または Visual Studio で AmidaAmida.sln を開き、デバッグ/実行を行ってください。

## エンドユーザー向け：操作手順（簡易）
以下はアプリ起動後の基本操作手順です。

- 起動
  - ビルドした実行ファイルを起動するか、Visual Studio で実行してください。

- 軸（縦線）の数変更
  - 画面右の ▲（上）/ ▼（下）ボタンで軸数を変更します。現在の値は AxisCountTextBox に表示されます。

- CREATE（生成）
  - 「CREATE」ボタンで指定した軸数に基づくアミダの初期表示を生成します。

- 横線の追加・編集
  - マウスでキャンバス上をクリック／ドラッグして横線を追加または移動します。
  - 操作を取り消す場合は「UNDO」ボタンを押します。

- FIX（確定）
  - 「FIX」ボタンで現在の横線配置を確定し、編集を無効化します。

- RUN（実行）
  - 「RUN」ボタンでシミュレーションを開始します。各軸の結果は下部のゴール領域や ResultMessage に表示されます。

- RESET（リセット）
  - 「RESET」ボタンで状態を初期化し、再度作り直せます。

- アニメーション速度
  - 右側のラジオボタン（Very Slow / Slow / Fast / Very Fast / Non Stop）でアニメーション速度を変更できます。

- Customize（カスタマイズ）
  - 「Customize」ボタンで表示キャラクターなどのカスタマイズを行います（ファイル選択や設定が開きます）。

- スクロール・表示
  - 中央のスクロール領域をドラッグまたはホイールスクロールで表示位置を移動できます。

- 設定の保存
  - ウィンドウ位置、軸数、アニメーション速度などは終了時に自動保存され、次回起動時に復元されます。

## トラブルシューティング
- 起動できない／ビルドエラーが出る場合
  - .NET 8 SDK がインストールされているか確認してください。
  - Visual Studio のターゲットフレームワーク設定が .NET 8 になっているか確認してください。
- 表示やマウス操作が期待通りでない場合
  - ウィンドウをリサイズして再描画されるか確認してください。
